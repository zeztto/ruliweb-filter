# ㄹㄹ필터

루리웹 목록에서 게시판, 게시판 탭, 제목 말머리를 기준으로 행을 숨기는 Chrome Manifest V3 확장 프로그램입니다. Chrome Web Store 배포본은 제공하지 않으며 아래 방법으로 source를 직접 로드합니다.

[루리웹](https://bbs.ruliweb.com/)의 공식 제품이 아니며 운영사와 제휴·후원 관계가 없습니다. 사이트명·게시판명·게임명 등 제3자 명칭의 권리는 해당 권리자에게 있습니다.

## 기능

- 베스트 목록과 개별 게시판 목록에 출처 게시판을 표시합니다. 중복되는 `게시판` 접미사는 표시에서 생략합니다.
- 게시판 표시를 누르면 해당 게시판 행을 숨깁니다.
- 개별 게시판에서는 현재 목록의 `구분`을 읽어 게시판별 탭을 표시하고 숨깁니다. 베스트 목록에는 탭 정보가 없어 탭 필터를 적용하지 않습니다.
- 제목의 시작 부분에 있는 `[말머리]`, `(말머리)`, `말머리)`, `말머리]`와 `/`로 나눈 말머리를 숨깁니다. 본문 중간의 일반 키워드 검색은 하지 않습니다.
- 목록의 `목록 필터`에서 필터를 바꾸거나 `필터 해제`로 전체 필터를 해제합니다.
- 옵션 페이지에서 표시·요청 제한·필터를 편집하고 필터를 JSON 문서로 가져오거나 내보냅니다.

## 설치

Chrome 또는 MV3를 지원하는 Chromium 브라우저가 필요합니다. 별도 build 단계나 npm 설치 없이 동작합니다.

1. 이 저장소를 clone하거나 ZIP으로 내려받아 압축을 풉니다.
2. `chrome://extensions`에서 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 있는 저장소 폴더를 선택합니다.
4. [베스트 목록](https://bbs.ruliweb.com/best/all)이나 개별 게시판 목록을 새로고침합니다.
5. 확장 프로그램 카드의 **세부정보 → 확장 프로그램 옵션**에서 설정을 편집합니다. 이미 열린 목록은 설정 변경 후 새로고침해야 반영됩니다.

확장은 `https://bbs.ruliweb.com/best*`와 `https://bbs.ruliweb.com/*/board/*`에 주입되며, 목록 요소가 없는 상세 페이지에서는 동작을 시작하지 않습니다. 사이트의 DOM 구조가 바뀌면 대응이 필요합니다. 모든 브라우저·모바일 화면과 현재 운영 사이트 DOM에 대한 호환성을 보장하지 않습니다.

## 권한과 데이터

- `storage`: 필터·표시 설정·게시판명 cache를 이 브라우저의 `chrome.storage.local`에 저장합니다. 계정 sync와 서버 전송 기능은 없습니다.
- `https://bbs.ruliweb.com/*`: 현재 목록의 URL·제목·구분·게시판명을 읽고, 목록에서 이름을 알 수 없는 게시판의 `/best/board/{boardId}`를 확인하는 데 사용합니다.
- 게시물별 상세 페이지를 가져오지 않습니다. 게시판명 확인 요청은 현재 루리웹 로그인 cookie를 포함할 수 있습니다.
- 기본 요청 제한은 페이지당 8개 게시판, 요청 사이 1500ms입니다. 옵션에서 상한 1–30개, 간격 500–10000ms로 조절합니다.
- 게시판명 cache 유효기간은 7일, 최대 500개입니다. 실패한 이름 확인은 10분간 재시도를 늦춥니다.
- 필터 문서에는 숨긴 게시판·탭·말머리가 들어갑니다. 자신의 관심사나 차단 목록이 드러날 수 있으므로 공개 저장소에 올리기 전에 내용을 확인하세요.

## 필터 문서

옵션의 **내보내기**는 화면에서 편집 중인 필터를 JSON으로 저장합니다. 문서 schema는 `ruliweb-best-tab.filters`, version은 `1`입니다. **가져오기**는 저장된 필터를 교체하며 화면의 표시 설정과 요청 제한은 유지합니다. 지원하지 않는 schema, 누락된 필터 map, 배열·문자열 등 잘못된 map 구조는 적용하지 않습니다. 3개 map이 모두 비어 있는 정상 문서는 모든 필터를 해제합니다. 저장 오류가 발생하면 성공으로 표시하지 않으며 기존 저장 데이터는 유지됩니다.

## 개발과 검증

Node.js 20 이상이 필요합니다. 외부 runtime·development dependency는 없습니다. 아래 검사는 Node.js 26.8.1에서 확인했으며 CI도 같은 버전을 사용합니다.

```sh
npm ci --ignore-scripts
npm run check
npm audit --omit=dev --audit-level=high
```

`check`는 세 JavaScript 파일의 syntax와 16개 core·storage 시나리오를 검사합니다. URL 파싱, 게시판명, 기본 설정, 게시판별 탭 key, 표시명, 필터 매칭, 문서 왕복, 대소문자, 말머리 경계, 요청 제한, 잘못된 map 거부, callback 오류, 옵션 저장·초기화 실패와 읽기 실패 시 변경 차단을 포함합니다.

`tests/fixtures/`는 실제 게시물 목록을 제공하지 않는 합성 테스트 전용 HTML입니다. `chrome.storage.local`의 작은 in-memory 대체물을 사용하므로 fixture 결과는 native extension storage 검증을 대신하지 않습니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

- `http://127.0.0.1:8765/tests/fixtures/best-list.html`
- `http://127.0.0.1:8765/tests/fixtures/board-list.html`

실제 확장 설치 후에는 게시판·탭 표시, 클릭·키보드 차단, 필터 해제, 옵션 저장 후 재로딩, JSON 내보내기·가져오기, 잘못된 문서 거부를 확인해야 합니다. 현재 source edition 검증은 자동 core·storage 검사, 브라우저 fixture와 운영 목록 DOM에서의 source 실행에 한정하며 브라우저 검증은 storage shim을 사용했습니다. native extension 설치·영속 저장소·자동 content script 주입은 별도 수동 확인 대상입니다. storage 오류 수정 후에는 자동 regression만 재검증했습니다.
